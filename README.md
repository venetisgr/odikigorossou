# Ο Δικηγόρος σου

Site όπου νομικοί ρωτούν πάνω στην ελληνική νομοθεσία και παίρνουν απάντηση τεκμηριωμένη στα ίδια τα άρθρα (RAG). Τα κείμενα προέρχονται από το [lexifina/greece-law](https://github.com/lexifina/greece-law)· η αρχιτεκτονική ακολουθεί το [taxgpt](https://github.com/venetisgr/taxgpt/tree/all-in-one-open-source).

Μία υπηρεσία, ένα container: FastAPI + στατικό frontend, χωρίς βάση δεδομένων. Οι συζητήσεις μένουν στον browser του χρήστη.

## Πώς απαντά

```
ερώτηση
  │
  ├─ 1. Planner (LLM, JSON)      γράφει 3–6 αναζητήσεις με τους όρους του νόμου
  │                              και προτείνει άρθρα που γνωρίζει («ΑΚ 914»)
  ├─ 2. Αναζήτηση (τοπικά)       BM25 σε SQLite FTS5, χωριστά για κώδικες / νόμους / π.δ.,
  │                              + άμεση ανάσυρση των προτεινόμενων άρθρων → έως 40 υποψήφια
  ├─ 3. Επιλογή (LLM, JSON)      κρατά έως 12 άρθρα· μπορεί να ζητήσει μία ακόμη αναζήτηση
  ├─ 4. (προαιρετικά) Ισχύς      διαβάζει τα άρθρα όπως ίσχυαν σε ημερομηνία (Global law API)
  ├─ 5. Συντάκτης (LLM, ροή)     βλέπει ΜΟΝΟ τα πλήρη κείμενα των επιλεγμένων άρθρων
  └─ 6. Έλεγχος παραπομπών       στον κώδικα: κάθε [n] πρέπει να δείχνει σε συνημμένο άρθρο
```

Το μοντέλο δεν απαντά ποτέ από μνήμη: οι αριθμοί άρθρων που προτείνει ο planner είναι μόνο υποδείξεις για το τι θα ανασυρθεί, και αν δεν βρεθεί τίποτα σχετικό δεν συντάσσεται απάντηση. Στο UI κάθε παραπομπή ανοίγει το άρθρο δίπλα, με ένδειξη για το τι είδους κείμενο είναι.

## Τι καλύπτει — και τι όχι

Το ευρετήριο (έκδοση 17.11.2026) έχει 110.120 άρθρα από 7.063 πράξεις: το Σύνταγμα, 20 κώδικες, 2.496 νόμους και 4.546 προεδρικά διατάγματα.

Τα όρια προέρχονται από το ίδιο το greece-law και φαίνονται σε κάθε πηγή:

- **Οι περισσότερες πράξεις υπάρχουν όπως αρχικά δημοσιεύθηκαν στο ΦΕΚ, χωρίς τις μεταγενέστερες τροποποιήσεις.** Αυτό ισχύει και για τον Αστικό Κώδικα (1984) και τον ΚΠολΔ (1985). Ενοποιημένο κείμενο έχουν το Σύνταγμα, ο ΠΚ, ο ΚΠΔ, οι φορολογικοί κώδικες και λίγοι νόμοι.
- **ΑΚ, ΚΠολΔ, ΚΔΔ, ΚΔΔιαδ, ΚΟΚ και οι παλαιοί νόμοι είναι OCR** σαρωμένων ΦΕΚ, με λάθη χαρακτήρων.
- Περιέχεται περίπου το ένα τέταρτο των νόμων από το 1975. Δεν περιέχονται νομολογία, υπουργικές αποφάσεις, εγκύκλιοι.
- Τα σήματα «όπως εκδόθηκε» / «OCR» εμφανίζονται στις πηγές, και ο συντάκτης έχει οδηγία να τα αναφέρει στις «Επιφυλάξεις».

Πριν από εμπορική διάθεση ελέγξτε τους όρους χρήσης των πηγών: το `LICENSE` του greece-law θεωρεί τα επίσημα κείμενα εκτός πνευματικής ιδιοκτησίας (ν. 2121/1993 άρθρο 2 παρ. 5), ενώ τα `source.json` του σημειώνουν ότι οι όροι του Εθνικού Τυπογραφείου (api.et.gr) αναφέρουν «προσωπική, μη εμπορική χρήση».

## Τοπική εκτέλεση

```bash
python -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"

tools/fetch_corpus.sh data/corpus                                    # ~1 GB λήψη, μόνο κείμενα
python -m dikigoros.indexer --source data/corpus --out data/index.db # ~40 δευτ., ~290 MB

cp .env.example .env    # συμπληρώστε LLM_API_KEY (ή LLM_BASE_URL=fake για επίδειξη χωρίς μοντέλο)
set -a; . ./.env; set +a
uvicorn dikigoros.server:app --port 8000
```

Tests: `pytest -q` (τρέχουν χωρίς δίκτυο και χωρίς μοντέλο, πάνω σε μικρό δοκιμαστικό corpus).

## Ρυθμίσεις

Όλες με μεταβλητές περιβάλλοντος· ο πλήρης κατάλογος στο [`.env.example`](.env.example).

| Μεταβλητή | Σημασία |
| --- | --- |
| `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` | Πάροχος με OpenAI-compatible `/chat/completions` (προεπιλογή TensorX / GLM-5.3 Flash, όπως στο taxgpt). `fake` = επίδειξη. |
| `LLM_ROUTER_MODEL`, `LLM_EXTRA_BODY`, `LLM_ROUTER_EXTRA_BODY` | Άλλο μοντέλο ή πεδία (π.χ. `reasoning_effort`) για planner/επιλογή και για τον συντάκτη. |
| `ACCESS_CODE` | Αν οριστεί, το site ζητά κωδικό. |
| `ASK_PER_HOUR` | Όριο ερωτήσεων ανά διεύθυνση (προεπιλογή 40). |
| `LAW_API_KEY` | Κλειδί Lexifina για τον ζωντανό έλεγχο. Χωρίς κλειδί: 10 κλήσεις/λεπτό, 100/ημέρα. |

## Ζωντανός έλεγχος (Global law API)

Η αναζήτηση γίνεται τοπικά, γιατί το δημόσιο API της Lexifina έχει χαμηλά όρια. Το API χρησιμοποιείται μόνο για ό,τι δεν έχει το ευρετήριο, και μόνο για άρθρα που το αρχείο παρακολουθεί ξεχωριστά (`art-*.md`):

- **«Ισχύς στις»** στη φόρμα ερώτησης: τα επιλεγμένα άρθρα διαβάζονται όπως ίσχυαν εκείνη την ημέρα (μία κλήση ανά ερώτηση)· όσα δεν ίσχυαν αφαιρούνται.
- **«Έλεγχος ισχύος και ιστορικού»** στον πίνακα του άρθρου: αν ισχύει σήμερα, ποιος νόμος το άλλαξε τελευταίος.

## Ανάπτυξη (Fly.io)

```bash
fly launch --no-deploy --copy-config
fly secrets set LLM_API_KEY=... ACCESS_CODE=...
fly deploy
```

Το `Dockerfile` κατεβάζει τα κείμενα και χτίζει το ευρετήριο μέσα στο image (το πρώτο build θέλει περίπου 10 λεπτά). Για επαναλήψιμο build καρφώστε την έκδοση του corpus: `fly deploy --build-arg CORPUS_REF=<commit>`. Ενημέρωση της νομοθεσίας = νέο deploy.

## Δομή

```
src/dikigoros/
  greek.py      αποτονισμός, stemming, αναγνώριση «Άρθρο N»
  corpus.py     ανάγνωση του greece-law σε πράξεις και άρθρα (3 μορφές αρχείων)
  indexer.py    χτίσιμο του SQLite/FTS5
  store.py      αναζήτηση BM25, εύρεση άρθρου από παραπομπή («ΑΚ 914», «ν. 4624/2019»)
  llm.py        OpenAI-compatible adapter (JSON + ροή) και λειτουργία επίδειξης
  lawapi.py     πελάτης του Global law API, με μνήμη και όρια
  pipeline.py   η ροή της απάντησης και ο έλεγχος παραπομπών
  server.py     API (SSE) + frontend
  prompts/      planner.md, selector.md, writer.md
  web/          index.html, app.js, styles.css (χωρίς build step)
```

## API

| Διαδρομή | |
| --- | --- |
| `POST /api/ask` | `{question, history, kinds, acts, as_of, previous_sources}` → ροή SSE: `status`, `plan`, `sources`, `text`, `check`, `done` / `error` |
| `GET /api/search?q=` | Αναζήτηση διατάξεων χωρίς μοντέλο |
| `GET /api/unit?uid=` | Πλήρες κείμενο άρθρου, προηγούμενο/επόμενο |
| `GET /api/live?uid=` | Κατάσταση του άρθρου σήμερα στο Global law |
| `GET /api/meta`, `GET /health` | Κάλυψη, ρυθμίσεις, κατάσταση |
